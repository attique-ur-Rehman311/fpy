📘 Web-Based Data Analysis and Prediction System

1. Introduction

The Web-Based Data Analysis and Prediction System is developed to provide users with an interactive dashboard for data visualization and a machine learning based prediction module. The system allows users to analyze historical vehicle sales data and predict car prices based on different input features.

2. Dashboard Module Report

2.1 Purpose

The dashboard module is designed to visually represent large datasets in an understandable manner. It helps users identify trends, comparisons, and patterns in vehicle sales and pricing data.

2.2 Data Source

The dashboard uses data loaded from a CSV file (data_sales.csv) which contains historical records such as model year, region, fuel type, mileage, sales volume, and price.

2.3 Dashboard Features

  • Dynamic charts generated using Chart.js
  • Multiple visualization types (Line, Bar, Pie, Doughnut, Radar)
  • Real-time filtering based on:
    • Year
    • Region
    • Model
  • Automatic chart updates without page reload

2.4 Visualization Purpose

  • Line Charts: Used to analyze price and mileage trends over time
  • Bar Charts: Used to compare sales volume between models and regions
  • Pie/Doughnut Charts: Used to show proportional distribution of sales
  • Radar Charts: Used to compare mileage patterns

3. Prediction Module Report

3.1 Purpose

The prediction module allows users to estimate the price of a vehicle based on selected attributes. This feature supports data-driven decision making and demonstrates the application of machine learning in real-world scenarios.

3.2 Input Parameters

  • Model Year
  • Fuel Type
  • Color
  • Transmission Type
  • Mileage (KM)
  • Engin size
  • Car model

3.3 Machine Learning Model

A regression-based machine learning model is used for price prediction. The model is trained offline using historical data and saved as a serialized file. During system operation, the model is only used for prediction and is not retrained.

3.4 Prediction Workflow

  1. User enters vehicle details in the prediction form
  2. Frontend sends data to the backend using JSON
  3. Backend preprocesses input values
  4. Trained model generates predicted price
  5. Predicted result is displayed on the screen

3.5 Output

The predicted price is displayed in a result card along with a visual chart representation to enhance user understanding.

4. Technologies Used

  • Frontend: HTML, CSS, JavaScript
  • Visualization: Chart.js
  • Backend: Django (Python)
  • Machine Learning: Scikit-learn
  • Database: SQLite

5. Conclusion

The Web-Based Data Analysis and Prediction System successfully integrates data visualization and machine learning into a single platform. The dashboard provides clear insights through dynamic charts, while the prediction module delivers accurate price estimations based on user input. This system is suitable for academic and analytical purposes and demonstrates practical implementation of data science concepts.
